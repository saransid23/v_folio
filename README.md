# Saran Siddarth — Cinematic Portfolio

A premium, high-performance video editing and cinematography portfolio website. Built with Next.js and designed to deliver a smooth, cinematic, and immersive user experience with advanced scroll animations.

🌐 **Live Demo:** [https://madebysaran.vercel.app/](https://madebysaran.vercel.app/)

---

## 🎨 Features & Design

- **Cinematic Experience:** Dark mode optimized, highly contrastive layout tailored for showcasing high-end video content.
- **Advanced Animations:** Custom GSAP scroll animations, staggering reveals, and kinetic typography.
- **Smooth Scrolling:** Integrated with Lenis for a buttery-smooth scrolling experience matching premium agency standards.
- **Optimized Media:** Leveraging Next.js Image components and optimized video rendering for lightning-fast load times.
- **Fully Responsive:** Beautifully scaled typography and grid layouts that work flawlessly on mobile, tablet, and desktop.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js 15](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [GSAP](https://greensock.com/gsap/) (ScrollTrigger), [Lenis Smooth Scroll](https://lenis.studiofreight.com/)
- **Deployment:** [Vercel](https://vercel.com/)

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/saransid23/v_folio.git
cd v_folio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application locally.

---

## 📦 Deployment to Vercel

This project is fully configured and ready for production deployment on Vercel. 

1. Push your code to GitHub.
2. Go to [Vercel](https://vercel.com/) and create a new project.
3. Import the `v_folio` repository.
4. Leave all build settings as default (Vercel automatically detects Next.js).
5. Click **Deploy**.

*Note: The project uses standard Next.js build commands (`npm run build`). No extra configuration is required.*

## 📝 Configuration & Customization

The site content is designed to be easily updatable. All the textual data, video links, social links, and experience records are stored in a single source of truth:

- **Data File:** `lib/data.ts` 
- Update this file to change your bio, social links, tech stack, or project descriptions without needing to hunt through UI components.
